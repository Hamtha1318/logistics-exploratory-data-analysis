# Logistics Exploratory Data Analysis (EDA)

## Project Overview
This project explores simulated logistics shipment data to identify patterns in delivery performance, shipping costs, warehouse workload, and shipment status.

## Objectives
- Calculate statistical summaries and logistics KPIs.
- Visualize delivery status and delivery duration.
- Compare average delivery times across cities.
- Analyze shipping costs by shipping method.
- Explore numerical correlations and potential outliers.
- Present business insights and recommendations.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.

## Dataset
The dataset contains 300 simulated shipments with city, distance, warehouse workload, shipping method, shipping cost, delivery duration, and status.

## Visualizations
The project includes delivery status, city comparisons, shipping cost analysis, delivery-time distribution, warehouse workload, correlation heatmap, outlier analysis, and shipping-method comparisons.

## Key Deliverables
- Jupyter notebook containing the EDA workflow.
- CSV dataset.
- PNG visualizations.
- Business insights report.

## Limitations
The dataset is simulated and does not represent actual company operations. Findings are educational and should be validated against real historical data before making business decisions.
